1 · Policy

The vault's authority is a 2-of-2 multisig: the agent's key and the guard's key. The agent can propose a payment, but the SPL Token program will not move anything without the guard's signature.

2 · The agent tries to pay

Each attempt runs the policy engine first, then hits the chain. Refusals in red were rejected by the policy; refusals in amber were rejected by Solana itself when only the agent signed.
